# kompagnon

a web app to make everyday life easier

# broad vision

kompagnon should be the primary tool to reduce mental load in everyday life.

this includes following areas:

- cooking (e.g. recipe management, week meal planning, shopping list)
- recurring household chores (e.g. laundry, trash takeout, cleaning)
- appointments (e.g. planned activities, holiday planning, birthdays, doctor appointment reminders)
- financial budgeting (e.g. receipt and bank account analytics)
